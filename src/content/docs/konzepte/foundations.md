**Foundations** sind die grundlegenden Technikkategorien der Kartenmagie, deren Beherrschung den Zugang zu einem breiten Repertoire an Tricks und Routinen öffnet. Wer die fünf Foundations kennt, kann die meisten starken Kartenroutinen erlernen und verstehen.

## Die fünf Foundations

### 1. Controls
Eine Karte unsichtbar an eine bestimmte Position im Deck bringen — typischerweise nach oben oder unten.

| Technik | Schwierigkeit |
|---|---|
| Double Undercut | Anfänger |
| Overhand Shuffle Control | Anfänger |
| Hindu Shuffle Control | Anfänger |
| Riffle Shuffle Control | Mittel |
| Pass (Classic Pass) | Fortgeschritten |

→ [Controls (Übersicht)](/techniken/controls/)

### 2. Forces
Den Zuschauer scheinbar frei wählen lassen — tatsächlich aber die Wahl bestimmen.

| Technik | Schwierigkeit |
|---|---|
| Riffle Force | Anfänger |
| Dribble Force | Anfänger |
| Touch Force | Anfänger |
| Classic Force | Fortgeschritten |

→ [Forces (Übersicht)](/techniken/forces/)

### 3. Switches
Eine Karte heimlich gegen eine andere austauschen — für den Zuschauer unsichtbar.

| Technik | Schwierigkeit |
|---|---|
| Double Lift | Anfänger |
| Top Change | Mittel |
| Color Change (diverse Varianten) | Anfänger–Fortgeschritten |

→ [Double Lift](/techniken/double-lift) · [Color Change](/techniken/praesentation/color-change)

### 4. Palmieren
Eine oder mehrere Karten unsichtbar in der Hand verbergen, während die Hand leer wirkt.

| Technik | Schwierigkeit |
|---|---|
| Finger Palm | Anfänger |
| Classic Palm | Mittel |
| Tenkai Palm | Fortgeschritten |
| Back Palm | Fortgeschritten |

→ [Palmieren](/techniken/palmieren)

### 5. False Shuffles
Das Deck scheinbar mischen, tatsächlich aber die Reihenfolge (ganz oder teilweise) beibehalten.

| Technik | Schwierigkeit |
|---|---|
| Overhand False Shuffle | Anfänger |
| Riffle False Shuffle | Mittel |
| Faro Shuffle | Fortgeschritten |

→ [Falschmischen](/techniken/falschmischen)

## Warum diese fünf?

Jeder starke Kartentrick lässt sich auf eine Kombination dieser Foundations zurückführen:

- **Control + Force** → Zuschauer wählt eine Karte, Magier weiß welche und findet sie
- **Switch + Control** → Ambitious Card (Karte kommt immer wieder nach oben)
- **False Shuffle + Control** → Deck wird "gemischt", gewählte Karte bleibt kontrolliert
- **Palm + Force** → Karte verschwindet und erscheint woanders

## Lernreihenfolge

Für den Einstieg empfiehlt sich:

1. **Double Lift** (Switch) — vielseitigste Anfängertechnik, Basis für Color Changes
2. **Riffle Force** (Force) — einfach, überzeugend, direkt nützlich
3. **Double Undercut** (Control) — unkomplizierter Einstieg in Controls
4. **Overhand False Shuffle** (False Shuffle) — gibt jeder Routine Glaubwürdigkeit
5. **Finger Palm** (Palmieren) — sanfter Einstieg ins Palmieren

Palmieren und der Classic Pass können später folgen — beide brauchen mehr Übungszeit und sind für erste Routinen nicht zwingend nötig.

## Foundations und Flourishes

Foundations sind nicht das Einzige, was sich zu üben lohnt. **Flourishes** wie der [Card Spring](/techniken/praesentation/card-spring) oder der [Charlier Cut](/techniken/praesentation/charlier-cut) gehören nicht zu den Foundations — sie täuschen nichts, sondern beeindrucken offen. Sie sind aber wertvolle Ergänzungen, die Routinen visuell aufwerten und als Misdirection dienen.

Sinnvoll ist eine Kombination: **Foundation-Techniken für die Substanz, Flourishes für die Wirkung.**
